使用提示：支持支付宝当面付、USDT收款、易支付(EasyPay)等多种支付方式，请确保配置信息正确。
⚠️ 关于支付回调（重要）
所有支付方式都依赖支付平台向 /api/notify/* 发送异步回调来自动发货（当面付 /api/notify/alipay、易支付 /api/notify/yipay、USDT /api/notify/usdt）。
  • Cloudflare 防护拦截风险：若开启了 Under Attack 模式、Bot Fight Mode 或新增了 WAF 拦截规则，支付平台服务器发来的回调 POST 可能被质询/拦截，导致付款成功但订单一直停留在待支付。此时请到 Cloudflare Dashboard → Security → WAF 添加 Skip 规则：URI Path 以 /api/notify/ 开头 → Skip 全部安全检查（回调自带签名/金额多重校验，跳过 WAF 不影响安全）。
  • 如何判断当前是否正常：如果当面付等现有支付方式能正常回调自动发货，说明当前 Cloudflare 配置未拦截回调，无需额外设置；但日后修改任何安全防护配置后需重新小额实测一笔。
  • 上线/换配置后建议：用 0.01 元小额订单实付一笔，确认订单能自动变为“已完成”并发货，再正式放量。
  • 排查方法：回调异常时查看 Workers 日志（Dashboard → Workers → Logs），搜索 Notify 关键词（如 YiPay Notify）可看到验签失败/金额不匹配等具体原因。

配置易支付 (EasyPay)
使用步骤
  1. 先在易支付平台（如彩虹易支付）后台开通商户，拿到 商户 PID 和 签名密钥；RSA 版本平台还需生成密钥对并获取 平台公钥
  2. 易支付版本怎么选：平台只给你一串「商户密钥」→ 选 v1 (MD5)；给你「商户私钥 + 平台公钥」→ 选 v2 (RSA)
  3. 选了 v1 (MD5) 怎么填：只填「商户密钥 (merchant_key)」一栏——把易支付后台的商户密钥整串复制粘贴进去（首尾别带空格/换行）；v2 的两个密钥框不用填
  4. 选了 v2 (RSA) 怎么填：填两个文本框——「商户私钥 (private_key)」粘贴你自己的 RSA 私钥（完整 PEM（-----BEGIN PRIVATE KEY----- 开头）或裸 Base64 都支持），「平台公钥 (platform_public_key)」粘贴易支付平台提供的 RSA 公钥（-----BEGIN PUBLIC KEY----- 或裸 Base64）；「商户密钥」一栏不用填
  5. 填写 网关地址（易支付平台域名，末尾不带 /）、商户ID 和对应的签名密钥；支付方式选你要在前台展示的收款通道（需易支付平台开通了该通道）
  6. 保存后，把 异步通知地址 填到易支付后台的「服务器异步通知地址」一栏（本页留空则默认 https://你的域名/api/notify/yipay），否则付款成功不会自动发货
  7. 先下一笔小额测试单，确认「付款成功 → 自动发货」流程跑通后再放量使用
