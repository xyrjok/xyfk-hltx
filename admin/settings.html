充值自动升级规则
当会员累计入金（自助充值 + 管理员手动加余额）达到设定值时，自动升级到对应等级。升级为单向（只升不降）。
注意：若管理员已手动设定某会员等级（会员管理里显示「手动」标记），则自动升级不会改动该会员等级，直到点「交还自动管理」。

Outlook (Graph API)
支持两种认证模式：
模式一（机密客户端）：适用于 Azure 后台创建的「Web」类型应用，需填写 Client ID + Client Secret + Refresh Token 三项。
模式二（公共客户端）：适用于「移动和桌面应用程序」类型应用（或已开启「允许公共客户端流」的 Web 应用），仅需 Client ID + Refresh Token 两项，Client Secret 留空即可。
两种模式均需在 Azure 后台为应用授予 Mail.Send（应用权限或委托权限）和 offline_access 权限，并由管理员完成授权同意。
机密客户端模式必须填写；公共客户端模式（无 Secret）留空即可，系统会自动适配。
请确保该 Token 拥有 Mail.Send 和 offline_access 权限。公共客户端模式下 Refresh Token 不会自动轮换，过期后需手动重新获取。
